3D Action Shooter

概要
Unityで個人制作している、3D見下ろし型アクションシューティングゲームです。

プレイヤーを操作して敵と戦い、部屋ごとに進行するステージを攻略していくゲームを目指しています。

現在もゲームシステムの設計・実装を進めています。

開発環境・使用技術
Unity 6000.4.2f1
C#
Universal Render Pipeline (URP)
Input System
UniRx

ゲームの特徴
キーボード・コントローラーの両方に対応した操作
見下ろし視点での移動・照準・射撃
複数種類の武器を使い分ける戦闘システム
部屋ごとに進行するステージ構成
武器の性能を強化するアップグレードシステム

実装・開発しているシステム

プレイヤー
移動・照準操作
回避アクション
ダメージ処理

武器
武器の装備・切り替え
射撃・弾薬管理・リロード
武器データのScriptableObjectによる管理
武器の種類に応じた射撃方式の切り替え

UI
武器スロットの表示
マガジン残弾数・予備弾薬数の表示
リロード状況の表示
UniRxを利用したゲームデータとUIの連動

技術的な工夫
ScriptableObjectを利用し、武器の性能や設定をデータとして管理することで、武器の追加や調整をしやすい構成にしています。
UniRxのReactivePropertyとSubscribeを利用し、ゲーム内の状態変化をUIに反映する仕組みを実装しています。
武器の射撃方式や弾の判定方法を設定によって切り替えられるようにし、武器ごとの仕様に対応できる構成を目指しています。
